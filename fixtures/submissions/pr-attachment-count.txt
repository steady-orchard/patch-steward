## Category

bugfix

## Problem

`widget parse` exits with status 1 on an empty file.

## Benefit

Empty files parse like any other valid document.

## Intended behavior

An empty file parses to an empty document and exits with status 0.

## Acceptance criteria

- `widget parse empty.txt` prints `[]`.
- Exit status is 0.
